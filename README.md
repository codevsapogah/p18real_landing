# P18 Схема Тест Landing Page

Modern, responsive landing page for the P18 Schema Test based on Jeffrey Young's schema therapy.

## Description

This landing page is designed to promote and sell the P18 Schema Test, which helps users identify their unconscious schema patterns that affect their life, relationships, and decision-making.

The page features:
- Modern, responsive design
- Eye-catching animations and transitions
- Mobile-friendly layout
- Clear call-to-action elements
- Pricing section
- Testimonials
- Feature highlights

## Technologies Used

- HTML5
- CSS3 (with custom properties, flexbox, grid)
- JavaScript (ES6+)
- SVG graphics

## Getting Started

1. Clone the repository
2. Open index.html in your browser

## Customization

### Colors

The primary color scheme can be modified in the `styles.css` file by changing the CSS custom properties in the `:root` selector.

### Content

Update the text content in `index.html` to match your specific requirements.

### Images

Replace placeholder images in the `images` directory with actual photos and graphics.
