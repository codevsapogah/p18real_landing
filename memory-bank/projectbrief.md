# P18 Schema Test Landing Page Project Brief

## Project Overview
The P18 Schema Test Landing Page is a modern, responsive web page designed to promote and sell a psychological test based on Jeffrey Young's Schema Therapy. The test helps users identify their unconscious schemas (early maladaptive patterns) that affect their life, relationships, and decision-making processes.

## Project Goals
1. Create a visually appealing landing page that effectively communicates the benefits of the P18 Schema Test
2. Encourage visitors to take the test by highlighting its value and benefits
3. Present pricing options clearly to facilitate conversion
4. Ensure the page is responsive and works well on all devices
5. Implement modern design principles and interactive elements to enhance user engagement

## Target Audience
- Adults interested in personal growth and self-development
- Individuals experiencing recurring problems in relationships or life patterns
- Psychology enthusiasts
- People seeking self-awareness and understanding of their behavior patterns
- Kazakh-speaking audience (primary language of the interface)

## Key Features
- Hero section highlighting the main value proposition
- Benefits and features section
- Schema type examples and visualization
- Testimonials from previous users
- Step-by-step guide to taking the test
- Pricing section with multiple tiers
- Mobile app download section
- Professional, trustworthy design aesthetic

## Design Requirements
- Modern, clean layout with ample white space
- Brand colors: Purple (#5856D6), Green (#34C759), Pink (#FF9AD5)
- High-quality imagery and illustrations
- Responsive design that works on all device sizes
- Gradient effects for visual interest
- Interactive elements (hover effects, subtle animations)
- Clear call-to-action buttons

## Technical Specifications
- HTML5, CSS3, and vanilla JavaScript
- Responsive design using flexbox and CSS grid
- No external frameworks required
- SVG icons and graphics for crisp rendering
- Web fonts (Inter from Google Fonts)
- Optimized performance for fast loading

## Content Requirements
- All text content in Kazakh language
- Compelling headline and subheadlines
- Clear explanation of the test and its benefits
- Pricing information with feature lists
- Testimonial quotes from satisfied customers
- Instructions for taking the test
- App store badges and download information

## Success Criteria
- Visually engaging design that communicates professionalism
- Clear and intuitive user flow leading to conversion
- Responsive layout that works perfectly on all devices
- Fast loading performance
- All interactive elements working correctly
